Nav header ("Bidang", "Project") dan menu-card kanan menautkan ke halaman kosong: user klik, layar jadi putih polos. Nav punya file tujuan tapi tidak ada isi; itu tautan mati dengan huruf berbeda.

4. **R-37** — Tidak ada `DESIGN.md` atau arah desain tertulis di repo. Identitasnya sebenarnya kuat dan spesifik (scrapbook kertas krem, folder biru, polaroid, kartu miring), tapi semuanya implicit di kode. Tanpa arah tertulis, edit berikutnya gampang menggeser identitas, dan filter ini tidak punya patokan mengukur konsistensi.

Yang tampil sekarang system-font default Tailwind: keputusan tipografi belum ada, dan satu request font mati setiap kunjungan. Pakai fontnya (misalnya di `.main-title`), atau hapus load-nya.
7. **R-04 / R-31** — Glyph `✦` (sparkle, ikon generik khas AI) di badge-card, bersama satu span kosong. Tidak mewakili apa pun tentang konten. Ikon relevan, atau tidak usah pakai ikon.
8. **R-31 / R-26** — Menu-card kanan (`index.html:136-154`) menduplikasi nav header (Home/Bidang/Project) sebagai kartu miring. `✓` hanya di "Home" (penanda halaman aktif yang tidak pernah diperbarui di halaman lain), `menu-icon` kosong semua, dan komentar di kode sendiri bilang "bingung ini mau diisi apa". Putuskan dan tuliskan: ini bagian scene dekoratif (kalau ya, pastikan tetap terbaca jujur sebagai hiasan) atau navigasi kedua (kalau ya, jangan duplikat dan jangan pakai penanda status yang tidak konsisten).

## Yang sudah bagus (pertahankan)

- Palet krem + gelap + satu aksen biru: hemat, konsisten, lolos R-29 tanpa palet liar.
- Motif identitas folder + polaroid + kartu miring: spesifik, bukan clone produk lain (R-30).
- Dialog photo viewer: tutup dengan Escape, klik backdrop, focus kembali ke kartu asal, prev/next, `aria-labelledby` (R-26/R-32 contoh yang benar).
- `aria-expanded`/`aria-controls` pada folder, `aria-hidden` di-toggle di photo stack.
- Handler scroll di-coalesce per frame (rAF) dan passive; tidak ada patch script (R-33 lolos).
- Tidak ada statistik, testimoni, atau klaim palsu (R-17/R-18/R-36 lolos); tidak ada buzzword (R-16 lolos); tidak ada emoji sebagai dekorasi (R-04 lolos untuk bagian lain).
- Gambar: semua referensi ada isinya, punya alt nyata, atribut width/height, `decoding="async"`, format webp.
- Glassmorphism ada di 2 elemen saja (header + backdrop dialog): di dalam dose cap R-10, alasannya cukup jelas (header mengambang di atas konten).
- Footer minimal dan jujur.
